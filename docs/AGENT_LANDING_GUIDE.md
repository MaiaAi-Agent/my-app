# Інструкція для агента: лендінги MASC у `MaiaAi-Agent/my-app`

Ти збираєш лендінги воронок MASC (марафон, вебінар, курс, лід-магніт) у цьому репозиторії і деплоїш їх на Vercel. Документ самодостатній: прочитай його повністю перед першою зміною. Якщо твій інструмент підтримує Claude Skills, те саме описано в `.claude/skills/masc-landing/` (там же скрипти перевірки).

**Еталон, з якого копіюєш:** `src/app/landings/ai-agents-marathon/` (у проді — корінь `/`). Нову сторінку роби копією еталона, а не з нуля.

---

## 1. Стек і обмеження

- Next.js **16** (App Router, TypeScript), React 19, pnpm, Biome. API Next 16 відрізняються від старих версій — перед використанням незнайомого API дивись `node_modules/next/dist/docs/` (див. `AGENTS.md`).
- Стилі: **CSS Modules**. Tailwind-класи не використовуємо (пакет лишився від шаблону, `globals.css` його не імпортує).
- Жодних UI/іконкових бібліотек (lucide, shadcn тощо). Іконки та ілюстрації — інлайн SVG (`Icon.tsx`, `AgentGraphic.tsx`).
- Шрифти підключені в `src/app/layout.tsx` через `next/font`: Manrope (текст, `--font-manrope`) і Unbounded 800 (hero, цифри, `--font-unbounded`). Нові шрифти — тільки там.
- Мова сторінок — українська, звертання на «ти».

## 2. Що запитати перед роботою (3–5 питань, не більше)

1. Назва кампанії і slug для URL (`ai-agents-marathon`). Чи має сторінка стати головною `/`? (Головна може бути тільки одна — перед заміною спитай.)
2. Оффер: формат, тривалість, ціна або «безкоштовно», дата старту.
3. Аудиторії (2–4): ключ (`switcher`), підпис кнопки, підпис у формі, заголовок і 1–2 речення.
4. Програма / що всередині (пункти по днях чи модулях).
5. Візуальний пресет (розділ 4). За замовчуванням для AI-агентів — dark-lime.

Чого не знаєш — познач як припущення у фінальному звіті, не вигадуй.

## 3. Правила текстів (обов'язково)

- Жодних гарантій результату і вигаданих цифр: «10x», «заощадиш 15 год/тиждень», «$1–3K», кількість випускників — тільки якщо користувач дав цифру і підтвердив, що вона реальна. Пиши «покажемо як», «потенційно», конкретні результати занять.
- Тільки реальні кейси, спікери, логотипи. Відгуки не вигадуємо.
- Заголовки ≤10 слів, дієслово на початку («Навчись», «Розпочни»).
- Якщо з назви дня програми дописуєш підпункти — скажи про це у звіті.

## 4. Дизайн-система

### Спільне для всіх сторінок
- Контейнер до 1120px, бокові відступи 16px. Секції розділені лінією 1px, відступи 56px (мобільна) / 80px (десктоп).
- Картки: рамка 1px, радіус 16px, фон трохи світліший за сторінку.
- Заголовок секції (h2): 800, трекінг −0.03em, **під ним акцентна риска 32×3px** (`.h2::after`).
- Акцентне слово в заголовках: `<span className={styles.accent}>`.
- **Hero:** бейдж капсом з точкою, що світиться → великий заголовок (Unbounded 800, капс, акцентне слово) → підзаголовок 1–2 речення → чіпи (дата, час, «Live online», «Безкоштовно»; дата — залитий акцентом) → головна CTA → дрібна сіра примітка.
- **Головна CTA:** залита акцентом, радіус 14px, висота 56px, жирний текст, стрілка праворуч, м'яке світіння. **CTA в шапці:** прозора з акцентною рамкою, pill, зі стрілкою.
- Плитки іконок: 48px, радіус 12px, рамка, іконка кольором акценту.
- Блок «…для тебе, якщо ти…»: 3 картки-кнопки з іконками, обрана — з акцентною рамкою; під ними картка з текстом для обраної аудиторії.
- Програма: номери «01 02 03» шрифтом Unbounded, кольором акценту.
- Футер: `MASC | Люди. Ідеї. AI-агенти. / Реальні навички для реальних задач.` + підкреслене акцентом посилання праворуч.
- Логотип: поки текст «MASC» + «Marketing / Automation School». Справжній лого (яйце) — SVG від користувача.

## 6. Форма заявки — контракт (не змінювати)

- Форма шле `POST /api/lead` з `{ email, audience, source }`. **Ніколи не шли напряму в n8n з браузера** і не хардкодь адресу webhook.
- `src/app/api/lead/route.ts` (спільний для всіх лендінгів) валідує дані, додає `timestamp` і пересилає `{ email, audience, source, timestamp }` на `WEBHOOK_URL` або `NEXT_PUBLIC_WEBHOOK_URL`, які читає **під час запиту**.
- Відповіді: 200 → стан успіху; 503 → «Реєстрація тимчасово недоступна» (змінна не задана); 502/400 → «Не вдалося надіслати заявку…».
- Перемикач аудиторії і `<select>` у формі — один state, синхронізація в обидва боки.
- Стани: `sending` (кнопка вимкнена) → `success` (`<output>` «Дякуємо! Перевір email», через 5 с знову форма) або `error` (`role="alert"`).
- Доступність: `aria-pressed` на кнопках перемикача, видимий фокус, кнопки від 44px, `prefers-reduced-motion`, без горизонтального скролу від 320px.

## 7. Перевірка перед пушем

```bash
pnpm lint                  # Biome; preview.html виключено в biome.json
pnpm build                 # лендінги мають бути ○ (static), /api/lead — ƒ (dynamic)

node .claude/skills/masc-landing/scripts/fake-webhook.mjs &      # тестовий webhook на :3999
WEBHOOK_URL=http://127.0.0.1:3999/hook PORT=3456 pnpm start &
node .claude/skills/masc-landing/scripts/check-landing.mjs http://localhost:3456/landings/<slug> .
node .claude/skills/masc-landing/scripts/snapshot.mjs http://localhost:3456/landings/<slug> src/app/landings/<slug>/preview.html
```

- `check-landing.mjs` перевіряє скрол на 375/1280, синхронізацію перемикача і форми, помилку на невалідний email, стан успіху і повернення форми; зберігає `landing-mobile.png` / `landing-desktop.png`. Подивись скріншоти і покажи їх користувачу.
- У лозі fake-webhook має бути рядок `PAYLOAD {...}` з правильним `source`.
- Скрипти потребують Playwright (`playwright` у проєкті або глобально; шлях до Chromium — змінна `CHROMIUM_PATH`).
- Типові зауваження Biome: замість `role="status"` використовуй `<output>`; після правок запускай `pnpm format`.
- Сервери зупиняй за PID. `pkill -f <шаблон>` вб'є і твій власний shell, якщо шаблон є в рядку команди.

## 8. Деплой на Vercel

Vercel-проєкт `maia-ai2/my-app` підключений до GitHub: **пуш у будь-яку гілку → Preview-деплой**, **мердж у `main` → Production**. Руками нічого деплоїти не треба.

1. Закоміть, запуш гілку, відкрий PR у `main`. Статус «Vercel» має стати success.
2. **Не давай користувачу адресу гілки** з коментаря `vercel[bot]` (`my-app-git-<гілка>-…vercel.app`) — вона не відкривається. Робоче посилання — хеш-адреса деплою `my-xxxxxxxxx-maia-ai2.vercel.app`: Vercel → Deployments → найсвіжіший Preview-рядок гілки → **Visit** (або посилання, яке надіслав користувач). По ньому користувач відправляє тестову заявку (має з'явитися в n8n → Executions).
3. Після підтвердження змерджи PR (squash) — Production задеплоїться сам.

### Змінні середовища (Vercel → Settings → Environment Variables)

| Змінна | Потрібна | Примітка |
| --- | --- | --- |
| `NEXT_PUBLIC_WEBHOOK_URL` (або `WEBHOOK_URL`) | так, вже задана | Спільна для всіх лендінгів, читається на сервері |
| `NEXT_PUBLIC_MARATHON_START` / інші змінні з датою | ні | Вшиваються під час **збірки** — після зміни потрібен Redeploy |

- Змінна має бути ввімкнена для **Production і Preview**.
- Зміни змінних діють тільки на **нові** деплої: Deployments → потрібний рядок → «⋯» → Redeploy. Redeploy рядка Production не оновлює preview гілки, і навпаки.
- Якщо в тебе немає доступу до Vercel — дай користувачу точні кліки, не вгадуй налаштування.

### Домен
Settings → Domains → додати, напр. `webinar.masc.space`, і CNAME у DNS `masc.space` на значення, яке покаже Vercel. Шлях на основному сайті (`masc.space/<slug>`) — це інший проєкт (`Trust60/nextjs-masc`), туди цей репозиторій не деплоїться.

## 9. Типові проблеми

| Користувач бачить | Причина | Що робити |
| --- | --- | --- |
| «Реєстрація тимчасово недоступна» | `/api/lead` → 503: у **цьому** деплої немає змінної webhook | Увімкнути змінну для Preview і Production → Redeploy саме цього деплою |
| «Не вдалося надіслати заявку…» | 502: n8n відхилив або недоступний | Vercel → деплой → Logs, рядок `[lead] …`; перевірити URL і що workflow в n8n активний (`/webhook/…` працює тільки для активного) |
| Стартова сторінка Next.js «To get started, edit page.tsx» | Відкрили Production-деплой `main` до мерджу | Відкрити Preview-деплой гілки або змерджити PR |
| Preview не відкривається / Chrome: «Did you mean claude.ai?» | Дали адресу гілки замість хеш-адреси деплою | Відкрити Vercel → Deployments → Preview-рядок → Visit (`my-xxxxxxxxx-maia-ai2.vercel.app`). Нові гілки називай `feat/<slug>-landing` |
| Не відкриваються next.masc.space / vercel.app з пісочниці агента | Мережеві обмеження середовища | Попросити скріншоти або дозволити хост у налаштуваннях середовища |

## 10. Фінальний звіт користувачу

Коротко: що зібрано і де (PR, Preview-посилання, скріншоти); де відступив від брифу і чому; що взято як припущення; що користувачу зробити перед запуском (тестова заявка, лист-підтвердження в n8n, дата, логотип, домен).

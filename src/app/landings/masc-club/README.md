# MASC Клуб — лендінг підписки

## Кампанія
- Slug / source: `masc-club`
- Продукт: клуб по підписці (бібліотека + живі дзвони + ком'юніті)
- Аудиторії (form audiences): `library`, `live`, `allin`

## Бонус флагмана
- Флагман з підтримкою → 6 міс All-in у подарунок
- Флагман з мастермайнд-групою → 12 міс All-in

Ціни флагманів на лендінгу клубу не показуються.
